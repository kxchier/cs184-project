# Fonts

The viewer uses **Velvelyne Light** by Manon Van der Borght and Mariel Nils,
with contributions by Raphaël Bastide and Benjamin Dumond.
[Original font page](https://velvetyne.fr/fonts/velvelyne/).
The file came from [this mirror](https://github.com/ilonamorch-a11y/kk/blob/main/Velvelyne-Light.woff)
because the foundry download was unavailable. It uses the CUTE conditions;
keep `Velvelyne-CUTE-EN.pdf` with the font.
[License source](https://genderfluid.space/documents/2024_BBB_CUTE-EN.pdf).

**Love Ya Like A Sister** by Kimberly Geswein is also included, but is no longer
used in the viewer. It came from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/loveyalikeasister)
and uses the SIL Open Font License in `LoveYaLikeASister-OFL.txt`.

Fonts load locally, without external requests.
